# 名前付き棋譜保存 / 開く / 対局再開

## UI
- ファイル → 名前をつけて保存 (`Ctrl+Shift+S`)
- ファイル → 開く (`Ctrl+O`)

## 保存
通常の `game_*.jsonl` をflushしてユーザー指定先へコピーする。既存棋譜JSONLと同じ形式なので棋譜並べでも読める。

## 開く / 続行
`ReplayLoader.Load` 後、初期状態から全着手を順に再適用して最終局面を復元する。この方法により、盤面と手番だけでなく**直前戻り制限の履歴と盤面4回判定の出現回数**も正しく再構築する。

復元後の人間/CPU割当やCPU棋力はメイン画面の現在設定を使用する。したがって保存棋譜を開き、途中局面から人間vsCPUへ切り替えて続行できる。

## 再保存
読み込んだ既存着手を新しい自動ログへseedし、その後の着手を追記する。「開く→続行→別名保存→再度開く」を繰り返しても保存ファイル単体で履歴を再現できる。

## 互換
現行棋譜は `rulesId=Standard`。旧標準相当ログはReplayLoaderの限定互換経路で読む。廃止済み実験ルールの棋譜は現在のゲームとして再開しない。

複数局入りHeadless batchはメイン画面の「開く」対象外で、棋譜並べを使用する。
