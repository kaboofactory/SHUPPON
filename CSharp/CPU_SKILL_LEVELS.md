# CPU棋力20段階 / 固定MaxNodes方式 — v0.2.36.6

## 方針

CPU棋力の自動校正機能は廃止した。
製品CPUの強さは **MaxNodes（1手あたり探索局面数上限）の固定表だけ**で決める。
意図的なRandomnessは使用しない。

- 15級: `200 Nodes`
- 1段階上がるごとに: `×1.80`（+80%）
- 共通探索Depth上限: `D99`（安全上限であり棋力値ではない）
- 時間制限: 製品CPUでは0（Node上限で停止）
- Randomness: 全段階0 / 使用しない

そのため五段は14,164,707 Nodes（約1,416万）になる。

## メイン画面

- `P1 CPU棋力` と `P2 CPU棋力` のComboBoxを常設。
- 選択肢は15級～五段の20段階。
- 人間(P1) vs CPU(P2): P2棋力だけ有効。
- CPU(P1) vs 人間(P2): P1棋力だけ有効。
- CPU vs CPU: P1/P2両方の棋力を個別指定可能。
- 人間 vs 人間: 両方無効。
- 既定はP1/P2とも5級。
- メイン画面の手入力Depth / TimeLimit / NodeLimitは廃止。
- `CPU探索スレッド` と `CPU間隔(ms)` は残す。

## 開発用ツール

`高速ヘッドレス` と `現在局面 深度ベンチ` は引き続き開発検証用として残す。
ここでは独自Depth/Node条件を指定できるが、通常対局の20段階棋力とは別用途。

## 過去の校正機能

v0.2.19.xで試した自動校正は、少数局の統計ノイズ・実行時間・運用コストが大きいためv0.2.20.0で完全撤去した。
`CpuSkillCalibrator.cs` / `CpuSkillCalibrationForm.cs` / 校正メニュー / 候補保存・標準採用フローは存在しない。

## v0.2.35.0 — MaxNodesを実質的な棋力上限にする

通常対局CPUの共通 `SearchDepthCap` は **99**。これは棋力を制限するためのDepthではなく、安全用の非常に高い天井である。
CPUはD1から反復深化し、原則として各棋力の固定 `MaxNodes` に達するまで深いDepthへ進む。途中DepthでNode上限に達した場合、その未完了Depthの暫定結果ではなく、直前に完了したDepthの結果を採用する。強制勝敗を証明済みの場合だけはNode予算を使い切る前に終了する。

v0.2.36.3でMaxNodes倍率を変更した（15級=200、1段階ごと×1.9235、五段=49,978,316）。
